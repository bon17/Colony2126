# 정착촌 헌장을 구글 시트로 받기

학생이 엔딩에서 「헌장 완성!」을 누르면 이름(번호), 제6조, 등급, 증거 정확도, 레벨, 클리어 시간이 선생님 구글 시트에 한 줄씩 들어와요.

## 만드는 법 (한 번만, 약 5분)

1. 구글 드라이브에서 **새 구글 시트**를 만들어요. 이름은 자유예요(예: 콜로니 2126 헌장).
2. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 눌러요.
3. 열린 편집기의 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣은 뒤 저장(디스크 아이콘)해요.
4. 오른쪽 위 **배포 → 새 배포**를 눌러요.
   - 톱니바퀴(유형 선택)에서 **웹 앱**을 고르세요.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르고, 권한 요청이 뜨면 내 계정으로 허용해요.
5. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요.
6. `colony2126/js/data.js`에서 `sheetUrl: ''`을 찾아, 따옴표 안에 그 주소를 붙여 넣어요.
   - 예: `sheetUrl: 'https://script.google.com/macros/s/AKfy…/exec',`
   - Claude에게 주소를 알려 주면 대신 넣어 줘요.

## 확인

- 웹 앱 주소를 브라우저 주소창에 열면 「콜로니 2126 헌장 받는 곳이 켜져 있어요.」가 보여요.
- 게임을 끝까지 하고 「헌장 완성!」을 누르면 결과 카드에 「선생님께 보냈어요 ✓」가 뜨고, 시트의 「헌장」 탭에 한 줄이 생겨요.
- 「보내지 못했어요」가 뜨면 학생이 「다시 보내기」를 누르면 돼요. 그래도 안 되면 결과 카드를 캡처해서 내요.
- 학생이 「제6조 고치기」로 다시 쓰면 새 줄이 하나 더 생겨요. 맨 아래 줄이 마지막으로 쓴 것이에요.

## 알아 둘 점

- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 바뀐 내용이 적용돼요. 주소는 그대로예요.
- 주소를 아는 사람은 누구나 시트에 줄을 보낼 수 있어요. 주소는 수업용으로만 쓰세요.
- 시트에는 학생이 쓴 이름(번호)과 제6조만 들어가요. 다른 개인 정보는 보내지 않아요.
- Claude 게임 링크(아티팩트) 안에서는 보내기가 막힐 수 있어요. 학생용으로 올린 페이지(GitHub Pages 등)나 내려받은 파일로 열면 보내져요.
